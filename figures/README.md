# Earlier visual outputs

These figures accompany the existing C++/Python benchmarks and refractor
examples. Parameter-sweep plots are stored with their own data under
`../results/`, which is the preferred entry point for comparing experiments.

`fig_refractor_3d_NK1600.png` is produced by `scripts/generate_results.py`.
Other plots are retained under their original filenames for provenance;
generic names such as `Figure_1.png` and `comparison_1.png` do not by themselves
identify a validated sweep or metric. Refer to the associated notebook/script
before using those historical figures as quantitative results.
