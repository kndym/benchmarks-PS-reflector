# Repaired kappa write-up capture

Completed capture: 120 paired cases per map, with all 40 cases in each of the
three experiments. The exact capture timestamp and hashes are in capture.json.

[Hard divergence](hard.csv) | [Entropic divergence](entropic.csv) |
[Hard mass error](hard_mass_error.csv) | [Settings and source hashes](capture.json)

The two worker groups have matching geometry, kappa=0.8, solver version and
optical tolerances. Each completed divergence record and its saved-map and
cross-checkpoint hashes were validated before capture. Duplicate case keys are
checked for numerical agreement and included once. Figures use paired cases.
Hard mass error is computed from saved hard endpoints with the saved source
weights, relative to all 1600 target weights, including empty locations.
