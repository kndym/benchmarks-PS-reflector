# Archived repository assets

Inactive visual exports and supporting files removed from the active repository
root. These are retained for reference; numerical run archives live under
[results/archive](../results/archive/) instead.

| Collection | Contents |
| --- | --- |
| [Legacy figures](legacy_figures_oct_27_26/) | Earlier benchmark charts and interactive visual exports. |
| [Root plot exports](root_plot_exports_oct_27_26/) | Plot files previously scattered in the repository root. |
| [Branding images](branding_images_oct_27_26/) | Historical EU/ROMSOC logos. |
| [Reference binaries](reference_binaries_oct_27_26/) | Previously built C++ executables; use current source/build instructions for new runs. |
| [Scratch diagnostics](scratch_diagnostics_oct_27_26/) | Earlier scratch notebook/script fragments. |
| [Site configuration](site_configuration_oct_27_26/) | Historical site configuration and its duplicate copy. |
| [Write-up exports](writeup_exports_oct_27_26/) | Older packaged write-up exports. Current editable LaTeX remains in [geometric_optics_progress](../geometric_optics_progress/). |

Here `oct_27_26` records the archive/catalog date, not an inferred date of
computation or authorship. Do not send new generated output into these folders.
