# Archived material

These files are retained for historical reproducibility, but they are not
part of the current default pipelines.

- `diagnostics/` contains the old `check.py`/`check.ipynb` Plotly scratch
  experiment. It depends on variables created by an interactive session and
  is not a standalone benchmark.
- `legacy/` contains the former self-contained refraction Sinkhorn script.
  The maintained implementation is now in `refracter/`.
- `reflector/` contains duplicate/standalone reflector generators superseded
  by the top-level `benchmark_reflector.py` pipeline.
