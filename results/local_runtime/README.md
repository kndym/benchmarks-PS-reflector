# Local worker runtime

Machine-local supervision state for scheduled computation. The
[worker supervision folder](worker_supervision/) contains status, process IDs,
pause/resume markers, and logs. It is not a numerical dataset or publication.

Check a worker's status and actual process before starting another instance.
Respect active pause markers. Completed numerical results belong in
[runs](../runs/) or [published](../published/); temporary logs and process state
stay here and are excluded from GitHub.
