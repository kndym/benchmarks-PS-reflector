# Published result captures

Validated captures for reading, plotting, and sharing. These folders separate
the numerical tables from figures and validation metadata. They are the best
starting point for the completed hard-versus-smooth comparison.

| Capture | What it shows |
| --- | --- |
| [Regular entropic error](regular_entropic_error_oct_27_26/) | All 120 cases per map using cross-EOT, with no self-term subtraction or square root. Includes large combined and individual plots. |
| [Debiased comparison](debiased_comparison_complete_oct_26_26/) | The same 120 pairs after subtracting both self-EOT terms. |
| [Complete smooth-refraction run](smooth_refraction_complete_oct_26_26/) | Optical/PF checkpoints, normal and unit-ray checks, settings, and cross-EOT comparisons. |
| [Hard-map mass error](hard_map_mass_error_oct_26_26/) | Maximum absolute discrepancy from prescribed target-atom mass. |
| [Hard-map occupancy](hard_map_occupancy_oct_26_26/) | Empty and merged target locations; an occupancy diagnostic rather than spatial transport error. |

Earlier partial captures are retained under
[archived progress captures](../archive/progress_captures/). A newer capture
does not turn an incomplete historical result into a completed run.
