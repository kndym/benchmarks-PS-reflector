# New reflector reference runs

Default output location for new standalone C++ and Python reflector benchmarks.
Each execution gets a descriptive dated run folder, with numerical TXT/NPY
files under `data/` and explanatory documentation beside that subfolder.

This category may contain no completed run yet. Historical reference outputs
are preserved separately in [the archive](../archive/reference_outputs/).
An explicitly supplied output directory is still honored by the relevant runner.
