# Refractor examples and controls

Saved NPZ bundles and small case studies used by notebooks and visualizations.
These are separate from the extended fixed-target sweeps in [runs](../runs/).

| Collection | Contents |
| --- | --- |
| [Uniform refraction](uniform_refraction_oct_27_26/) | The standard uniform-source/uniform-target notebook bundle. |
| [Density pairs](density_pairs_oct_27_26/) | Sixteen combinations of uniform, Gaussian, donut, and cross densities. |
| [Additional refraction example](refraction_example_oct_27_26/) | The separately saved example NPZ. |
| [Refractor surfaces](refractor_surfaces_sep_24_26/) | Default and random spherical-patch examples, with source and surface images. September 24 is the latest saved numerical revision. |
| [Uniform sensitivity](uniform_sensitivity_oct_02_26/) | Ten kappa/source-angle controls. Numerical files were first saved October 2; surface images were added later. |

For the three collections ending `oct_27_26`, the date records their catalog
organization when an original computation date was unavailable. It does not
claim that these numerical examples were rerun on October 27.
