# Sinkhorn refracter examples

Generated by `scripts/generate_sinkhorn_refracter_examples.py`.

## Method

- Seed: `20260914`; cases: `11` (1 default + 10 random); NK: `400`.
- Every cloud is sampled uniformly in spherical area: azimuth is uniform and the cosine of the polar angle is uniform.
- Source and target weights are both discrete uniform measures, with one atom of mass `1/NK` per point.
- The surface is `Ref_i = 2 R_i x_i`, with `R_i = exp(f_i)` from the Sinkhorn-divergence-corrected source potential.
- The hard c-transform map uses the raw OT target potential: `j*(i) = argmin_j [c(x_i,y_j) - g_raw_j]`.
- `W₁(angle)` is the exact equal-mass assignment cost from the pushed source atoms to the uniform target atoms, using `arccos(y·y')` in radians. The xy and 3-D `W₂` values use squared Euclidean costs and report the square root of the mean assigned squared distance.

The new `validate_transport_possible` check was run for every case before Sinkhorn. `target_fully_covered` means every generated target point lies inside the requested target theta/phi bounds; `finite_cost_reachable` means every source-target pair passes the strict finite-cost condition.
