# Archived numerical material

Historical, superseded, partial, and diagnostic results retained for provenance.
Use [published](../published/) for completed current comparisons and
[runs](../runs/) for their working datasets.

| Folder | Contents |
| --- | --- |
| [Historical runs](historical_runs/) | Earlier pilot and expanded sweeps, including varying target sizes and internal-solver metrics. |
| [Superseded runs](superseded_runs/) | Replaced attempts, preserved with their original completion limits. |
| [Progress captures](progress_captures/) | Partial optical/debiased captures and intermediate write-up updates. |
| [Exploratory studies](exploratory_studies_oct_06_26/) | Density, convergence, refinement, and evaluation controls completed October 6 and packaged October 22. |
| [Desktop shards](desktop_shards/) | Original partial desktop contributions used during consolidation. They are not independent additional experiments. |
| [Reference outputs](reference_outputs/) | Earlier C++/Python arrays and reflector NPZ bundles. Similar names do not guarantee identical contents. |
| [Smoke checks](smoke_checks/) | Small implementation checks, separate from production numerical runs. |
| [Repository consolidation](repository_consolidation_oct_26_26/) | The validation record for combining desktop and laptop result bundles. |

Date suffixes retain recorded run/capture dates. On undated legacy material,
`oct_27_26` means the organization date; each collection explains that distinction.
