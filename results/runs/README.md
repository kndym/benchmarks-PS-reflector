# Numerical runs

Canonical working datasets, reusable solve checkpoints, and evaluation tables.
Start with each run's README; use `data/` for numerical tables, `plots/` for
figures, and `metadata/` for settings and validation.

| Run | Purpose |
| --- | --- |
| [Standard fixed-target sweep](standard_fixed_target_oct_22_26/) | Smaller hard-map parameter sweep, including the independent evaluation-epsilon experiment. October 22 is its publication date. |
| [Hard map, 17 updates](hard_map_17_updates_oct_08_26/) | Extended 120-case baseline with inherited final-loop limits. |
| [Hard map, 2000 updates](hard_map_2000_updates_oct_08_26/) | Matching extended hard-map sweep with higher final-loop limits. |
| [Smooth refraction, 2000 updates](smooth_refraction_2000_updates_oct_26_26/) | Softmin-surface normals and Snell refraction on the same extended grid. |
| [Debiased comparison](debiased_comparison_oct_26_26/) | Saved cross and self EOT terms, separated into hard and entropic maps. |

Raw cross-EOT, debiased Sinkhorn divergence, optical solver costs, and marginal
residuals are different quantities. Read the run's metric definition before
comparing its tables. Final presentation captures live in [published](../published/).
