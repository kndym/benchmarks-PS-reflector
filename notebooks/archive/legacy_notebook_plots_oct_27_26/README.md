# Legacy notebook plots collected October 27, 2026

These files were moved byte-for-byte from the notebook root during repository cleanup. They mix reflector and refractor previews and do not form a new numerical experiment. The date in this folder name is the collection date, not a claim about when the calculations ran.

- [Static plots](plots/): original PNG filenames preserved.
- [Interactive HTML](interactive/): saved optical 3D preview.

New notebook exports go to dated folders under `results/notebook_outputs/`; these archived files are not overwritten by reruns.
